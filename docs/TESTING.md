# 怎么测《忒修斯之脑》

这份文档分两半，互不重叠：

- **第一部分**是给试玩者的。**可以整段复制发给任何 AI**，里面没有剧透。
- **第二部分**是给维护者的：机器该查什么、怎么复现别人报的 bug。

分开写是有道理的——**这两半找的是完全不同的 bug，而且互相找不到对方那一类。**

---

# 第一部分 · 给试玩者（可整段复制）

> 下面这段可以原样发给任何 AI。它不含任何剧透。

---

请帮我试玩一个文字游戏并找 bug。它叫《忒修斯之脑》，通过 MCP 提供接口。

**怎么接**：把 `server.py` 的绝对路径填进你的 MCP 配置

```json
{ "mcpServers": { "theseus-brain": { "command": "python3", "args": ["/绝对路径/server.py"] } } }
```

没有 MCP 环境的话，`python3 server.py --cli` 是终端交互版。
**但试玩请走 MCP**：CLI 是给人自己坐在终端前玩的，它不会弹玩法菜单（人已经在场了），
「你转述得舒不舒服」这一类问题在 CLI 上根本测不到。

**怎么玩**

1. 调 `new_run`。**第一次不要填任何参数**——引擎会返回一张玩法菜单，请把它念给我，我来选。
2. 之后按我选的模式玩下去。工具：`choose` 选项、`status` 看状态、`legacy` 看历史、
   一世结束后 `bequeath` 写词条，然后再 `new_run`。
3. **至少玩三世。** 这个游戏的机关在跨世那一层，一世看不出它在干什么。
4. **按角色的处境和性格选，不要挑成功率最高的。** 失败的文案往往比成功的好。

**我要你留意的四类问题**

1. **认错人**——某段文字表现得像是"认识"你，但你没做过对应的事；
   或者反过来，你明明做过一件事，后面完全没有痕迹。
2. **对不上**——选项写的和结果发生的不是一回事；
   或者某句话提到了一样你从没见过、也无从知道的东西。
3. **读不懂**——引擎给的提示看不明白（比如某个选项灰着，但你不知道为什么）。
4. **不舒服**——转述给我的节奏。战报行够不够？状态看得清吗？哪一幕拖？

**怎么报**

发现问题的时候，**先调一次 `status`，把输出原样贴给我**，然后用一句话说哪里不对。

`status` 的最后两行长这样：

```
复现：第 3 世 · seed=1837462910 · 本世选择=1,3,2
完整重放：[[71,[1,1,3]],[884,[2,1,1,2]],[1837462910,[1,3,2]]]
```

**这两行是关键。** 有了它我们能把你玩的这一局一模一样地重跑一遍。
没有它，"刚才那里怪怪的"就查不下去了。

**三件不用做的事**

- 不用给我剧情复述。我要的是"哪里卡住了"，不是"发生了什么"。
- 不用夸。作者要的是能改的意见。
- 不用担心玩坏。存档在 `saves/`，删掉就从头开始。

# 第二部分 · 给维护者

## 三层防线，各查各的

| 层 | 命令 | 拦什么 | **拦不住什么** |
| --- | --- | --- | --- |
| **门禁 ＋ 自测** | `--selftest` | 数据完整性、崩溃、数值不变量 | 文案好不好，内容有没有人读得到 |
| **覆盖报告** | `--coverage N` | **写了却永远不触发的内容** | 文案对不对、通不通 |
| **人／AI 试玩** | 见第一部分 | 认错人、对不上、读不懂、不舒服 | 上面两类，一个都找不到 |

**第三层找不到第二层那一类，这一点值得说清楚。** 没有人会为了验证一条回响连玩两千世。
反过来，前两层永远读不懂一句话通不通。**所以三层都得跑，而且顺序是从便宜到贵。**

## 一、`--selftest`（每次改完必跑）

```bash
python3 server.py --selftest
```

七道门禁 ＋ 400 局随机自动游玩 ＋ 二十来项定向验证。任何一项不过直接失败。

| 门禁 | 拦什么 |
| --- | --- |
| `lint_events` | 通用文案里出现阵营专名／事件 id 重复／碎片门票不自洽 |
| `lint_skill_names` | 技能表之外的名字（**写在检定里会当场崩**） |
| `lint_dead_echoes` | 回响／变体／条件尾巴没有条件键（**写了却永远不触发**） |
| `lint_option_hints` | 选项文案里手写数值门槛（门槛只归 `req` 管） |
| `lint_author_marks` | `【】` 里漏下的作者指令跟着上线 |
| `lint_spoilers` | NPC 台词里出现复现指涉（上次／又是你／第几个……） |
| `lint_retire` | 一条会退场的线，把别的幕唯一的钥匙一起带走了 |

〔第七道是最新的一道：**六十条弧线各自声明了在哪里讲完**，
讲完就不再出现。这道门禁查的是「退了场会不会把别人的钥匙一起带走」。〕

后两道门禁**误判过好几次**。处理惯例是：**规则不放宽，句子改掉。**
几乎每一次误判都逼出了更好的句子——这条经验写在 `docs/引擎修订记录.md` 里。

## 二、`--coverage N`（加完内容之后跑）

```bash
python3 server.py --coverage 2000
```

随机跑 N 世，报告：从没抽到的事件、极稀有事件、**从没触发过的回响**、
从没命中过的整幕变体、没拿到的成就、缺的碎片。

**怎么读这份报告**：有几行天生就是空的，别当 bug。

| 天生走不到 | 为什么 |
| --- | --- |
| 「湖」与「终局」那条路 | 需要在特定时刻**打字说对一句话**。随机游玩不会打字 |
| 需要连续投胎同一派系的内容 | 一个派系是八分之一，连中三次期望三十世以上 |
| 需要玩家**刻意去追**某条线索的内容 | 随机选项不会有意图 |
| 会退场的线讲完之后的那些 | 一条线要见够次数才退场，随机档案只走得完它待过的那几档 |

**真正要查的是这两种**：

1. **事件从没抽到过** —— 权重太低，或者 `req_seen` 的门开在一个抽不到的地方。
2. **回响从没触发过，而它的条件并不苛刻** —— 多半是条件写错了，
   比如挂在一个这辈子拿不到的 flag 上。

〔**基线（2026-08-08 · 退场表上线后）：1500 世，事件 69 个零死角，
整幕变体 30 个未命中 6 个，回响 139 条未触发 41 条。**

未命中的那 6 个变体全部是「要玩家刻意去追」的：狗线四个变体（要连续几世
善待同一条狗）、河堤的空河堤（要走完四幕并动那台手术）、
铁锤派的战利品墙（要先跑过一趟灰港）。**随机游玩追不到，不是 bug。**

回响未触发数比早先高，原因是覆盖工具每 12 世换一份干净档案 ——
不换的话派系会被锁死，换了则跨世事迹攒不起来。**两害相权取前者：
「事件零死角」比「回响触发率」重要得多。** 事件那一行出现名字就要查。〕

## 三、复现别人报的 bug

试玩者贴过来的 `status` 里有一行：

```
完整重放：[[71,[1,1,3]],[884,[2,1,1,2]],[1837462910,[1,3,2]]]
```

原样喂给：

```bash
python3 server.py --replay '[[71,[1,1,3]],[884,[2,1,1,2]],[1837462910,[1,3,2]]]'
```

它会另开一个临时存档目录（**不碰你自己的轮回档案**），把每一世的每一幕连同选择
全部打印出来。落点与原局一致——自测里有一条断言专门验这件事。

**为什么脚本里要带上前面几世**：世界记忆（跨世事迹、已见事件、时代）会改变
同一个种子的走向。只给最后一世的种子是重现不出来的。这一点实测确认过：
同一种子在空档和有记忆的档上会走出不同的局。

## 四、加了新内容之后的完整流程

```bash
python3 server.py --selftest        # 七道门禁 + 400 局，必须全绿
python3 server.py --coverage 2000   # 新加的回响有没有一条是死的
python3 docgen.py extract           # 重新生成修改表与通读稿
```

然后再交给人／AI 试玩。**前两步是免费的，第三步是花钱的——别把免费能查的事拿去花钱查。**

## 五、关于试玩者给的意见

试玩反馈里最值钱的一条，往往不是他说"这里有 bug"，而是他说
**"我觉得这个世界的真相是……"** ——然后猜错了。

猜错说明线索给少了或者给偏了。**这一类只有试玩能告诉你，而且它比任何 bug 都重要。**
所以第一部分那段话里没有任何剧透——**一个知道答案的试玩者，测不出线索够不够。**
