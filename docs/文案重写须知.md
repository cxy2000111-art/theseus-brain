## 一、工作流

0. **先把工作台生成出来**（仓库里不存这一份——它是从 `server.py` 现生成的，
   存一份进仓库只会跟源码走散，而且通读稿等于把全部剧情按顺序摊开）：

   ```bash
   python3 docgen.py extract     # 生成 docs/修改表-*.md 四册 + docs/通读稿.md
   ```

   ⚠️ **通读稿是完整剧透**。只想玩的人不要 extract。

1. 四册修改表在 `docs/`，格式：`### [编号] 位置` → 【原文】 → 【新文】。
   **【新文】留空＝沿用原文；写了＝整段替换。编号、位置、【原文】不要动。**
2. `docs/通读稿.md` 只读，用来找上下文。
3. 贴回：`python3 docgen.py apply docs/修改表-*.md`，然后跑自测。
   贴回按【原文】定位——四册可以分给不同 AI 并行改，但**同一段只能改一次**。
4. 手机／WPS 请关自动更正：「」被换成引号就贴不回去了。

### 她填的是 .docx

她在 WPS 里填四列表格（编号／位置／原文／新文），不直接改 md。两个方向都已脚本化：

```bash
python3 docxio.py todocx  docs/修改表-X.md 出.docx [--only 编号,…] [--title 标题]
python3 docxio.py fromdocx 填好的.docx docs/修改表-X.md      # 写进【新文】
python3 docxio.py cover   她填过的.docx docs/修改表-X.md      # 她没过目过的编号
```

- **发给她的文件名必须是纯英文**：上传／下载会把中文文件名吃成下划线。
- `fromdocx` 会把自动更正吃掉的 `“ ”` 还原成「」并逐条打印。**关掉自动更正仍然是上策。**

## 二、底牌：全城只有玩家一个人能带着记忆转世

纯血线真结局（血的证词）才揭。所有文案为它让路。
**新写任何文案时不得引入「别人也转世／大家都转世」的暗示。**

### 回响只写行为，不写原因（最要紧的一条）

NPC **可以有反应，不能有结论**。

- ✗ 「你上回也这么站着看。」「我数过，你是第几个了。」
- ✓ 「船长收钱的手停了一下，然后找零时多给了两个硬币。他没解释，你也没问。」

**规则：可以写停顿，不能写停顿的原因。** 注意到，是玩家的功劳。

## 三、七道门禁

| 门禁 | 拦什么 |
| --- | --- |
| `lint_events` | 通用事件正文出现阵营专名（纯血誓约／圣殿派／灰港／明焰……）；事件 id 重复；碎片门票不自洽 |
| `lint_skill_names` | 技能表之外的名字。**写在检定里会当场崩** |
| `lint_dead_echoes` | 回响／变体／条件尾巴没有条件键（**写了却永远不触发**） |
| `lint_option_hints` | 选项文案里手写数值门槛（见 §五） |
| `lint_author_marks` | `【】` 里漏下的作者指令跟着上线 |
| `lint_spoilers` | NPC 台词里出现复现指涉（上次／又是你／眼熟／老主顾／熟客／几代人……） |
| `lint_retire` | 一条会退场的线，把别的幕唯一的钥匙一起带走了（见 §六） |

**误判过好几次。处理惯例是：规则不放宽，句子改掉。**
几乎每一次误判都逼出了更好的句子。

## 四、笔法

1. **群像换单数**：「一排拔下来的牙」→「一枚孤零零地躺着，像一颗被拔下来的牙」。
2. **删解释，留动作**：「是被人取走了什么」→「是人为的」。
3. **政治沉到地面**：贫民窟、老鼠、406、铅笔写的名单——阶层写进感官细节，不写进议论。
4. **镜像结构**：同一句话接在得救与死亡后面各念一遍。
5. **感官具体，文化标记去掉**：「一碗最便宜的清汤面，葱花七粒」；人名不出现（406 式代称）。
6. **每段结尾问一次：这句是在给画面，还是给结论？** 是结论就删。
   〔判断标准：删掉最后两行，这一段是不是变强了？大部分时候是。〕
7. **不写公元纪年，不写地球上的人名地名**。神话底料（忘川、谟涅摩绪涅）可以，
   有具体地球坐标的不行。〔`半人马座` 是唯一的例外，作者定案保留。〕

## 五、文案里不写门槛

**选项文案里不出现任何数值门槛**——机化率、印记次数、跨世条件，一个都不写。
门槛只归 `req` 管；选项被挡住时引擎自己会打印
「✗ ……（不可选，需要 机化率达到 20%）」。

手写的那一份从头到尾是冗余，**而冗余的那份还会撒谎**（引擎一改它就过期了）。
`lint_option_hints` 是硬门禁。

## 六、写新事件时必须表态的三件事

### 1. 机化率档位

> 「都快飞升了还在中介门口找工作看起来好好笑。」——作者

| 档 | 写法 | 谁在这一档 |
| --- | --- | --- |
| 常驻 | 不写 | 雨市、传教士、临终、狗、停电、夜图书馆、身体税、老歌手、夜渡、残响、深夜敲门 |

〔「常驻」说的是**哪一档身体遇得到**，和「会不会讲完」是两件事：
现在除了深夜敲门，常驻的那些也各自会讲完。〕
| 低机化专属 | `max_aug=69` | 中介所、改装师 |
| 高机化专属 | `min_aug=40` | 超频、河堤、楼下的歌声 |

### 2. 退场条件（写进 `RETIRE_POLICY` 那张表）

**这一幕是这座城的天气，还是一条有始有终的线？**

- **天气**永不退场。**现在只剩深夜敲门一个** —— 它不是故事，
  是疑云攒够了自己找上门来的那一下。岔口与三问也永不退场（它们是机关，不是戏）。
- **弧线**讲完就退场：有终点动作的写 `{"deed": x}`，读完就完的写 `{"seen": N}`。
- **一个变体自己也可以讲完**：变体里写 `"retire_after": N`
  （「朋友的新眼睛」问三次就问完了，而岔口本体永远都在）。

**「见过 N 次就退场」会把 ≥N 的回响变成死文案** —— `lint_retire` 会当场抓住。
三次退场就该配三个版本：本体、变体1（≥1）、变体2（≥2）。

**`seen` 门槛不能低于别人对这一幕的 `req_seen`**——`lint_retire` 会替你查。

- **这一幕手里攥着别人的钥匙？** 写 `{"seen": N, "keep_until": "flag名"}`。
  读作「钥匙没交出去之前不许走」——次数到了也照样出现，交出去之后按 N 退场。
  金叶子那条链的两道门（`entered_chapel`／`denied_the_leaf`）就靠这一条：
  少了它，一个从没跟进过教堂的人第三次之后就永远够不着全书终，
  **而他不会知道自己失去了什么。**

**每一条线都走过一面、而且走完了金叶子那条路，会念一段「全书终」。**
〔不要求刷满退场次数 —— 走过一遍就算走过。〕

### 3. 这一幕的钥匙会不会被带走

如果某个 flag **只有一条会退场的线**给得出来，而别的幕在等它，
那条线一退场，那些幕就永远开不了门。`lint_retire` 会拦。

## 七、引擎里真实存在的机关（只有这些）

| 你想要的效果 | 写法 |
| --- | --- |
| 只有某派系能遇到 | `subs=["灰港"]` |
| 跨世见过某事件 N 次才解锁 | `req_seen={"事件id": N}`（与） |
| 几个入口任一即可 | `req_seen_any={"A": 1, "B": 1}`（或） |
| **做过某件事才出现** | `req_deed={"flag名": N}` |
| 某个选项要有前提 | `"req": ("deed", "flag名", N)` / `("skill", 技能, N)` / `("aug", ">=", N)` / **`("seen", "事件id", N)`** |
| 前提有两条路都算 | `"req": ("any", [(…), (…)])` |
| 跨世回响 | `echoes=[{"deed": "x", "min": n, "text": "…"}]` |
| 回响要同时满足两条 | `{"all": [ … ]}`；任一即可用 `{"any": [ … ]}` |
| 第 N 次来时整幕换一版 | `variants=[{"seen": "事件id", "min": n, "text": …, "options": […]}]`（**靠后的赢**） |
| 只换选项、不换正文 | 变体里不写 `text`（**回响照给**） |
| 某个结局多长一段尾巴 | 结局里写 `"extra": [{"deed": "x", "min": n, "text": "…"}]` |
| 尾巴要连这一世刚做的也算 | 条件里加 `"now": True` |
| 技能 ≥8 时开口 | `voices={"逻辑": "【逻辑】…"}`（必须带【技能名】前缀） |
| 不掷骰、按之前做过什么分岔 | `"gate": ("flag", "x")` / `("deed", "x", n)` / **`("seen", "事件id", n)`** 配 `success`/`failure` |
| **五五开，与角色无关** | `"coin": True` 配 `success`（正面）/ `failure`（背面） |
| 这一世掏空过兜 | `"gate": ("noflag", "broke")` |

**引擎里没有的东西**：选项旁白（写成 `echoes`）、全局回响（必须挂在具体某一幕上）、
`{"deed": "a", "flag": "b"}` 这种双键（写成 `{"all": [ … ]}`）。

### 换了 `text` 的整幕变体不继承基础事件的回响

给一个基础事件写变体时，**原来挂在它身上的回响要一起搬进变体里**，
否则那些回响从变体上线那天起就再也不出现。
搬的时候要重写：宿醉的人不会「主动递半个拍子给你」。

### 八个技能，一个都不能多

> 逻辑 · 共情 · 威慑 · 巧手 · 坚忍 · 街智 · 机械亲和 · 电子直觉

「感知」「意志」「话术」「机械直觉」都不存在。检定难度区间 **8–12**
（全游戏只有一个 13：邀请 cc 机械飞升）。收益：成功 +2，失败 +1，**失败也要给**。

### 一条长链的第一道门不掷骰

掷骰该出现在「这一次做得成做不成」上，**不该出现在「你有没有资格开始」上**。
金叶片那一问原先是逻辑 9，失手一次就把后面四幕全锁死，
而玩家永远不会知道自己失去了什么。现在它无检定。

## 八、边界

引擎不校验记忆词条真伪：**写谎不是作弊，是玩法；改数字才是作弊。**
封存模式是约定不是锁：封「转述」，不封「事实」。
